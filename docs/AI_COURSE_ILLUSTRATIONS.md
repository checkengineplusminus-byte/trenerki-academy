# Ilustracje autorskie AI bez tajemnic

32 osobne, wektorowe pliki SVG, po jednym na lekcję 1–32, w public/academy/assets/.
Grafiki są tworzone kodem w projekcie TRENERKI, bez importowanych zdjęć, logotypów ani znaków wodnych.
Każda sekwencja trzech ilustracji odpowiada odrębnemu zadaniu lekcji (od danych, przez działanie, do kontroli), ale NIE jest dowodem wykonania ćwiczenia przez ucznia.
Obrazy nie zawierają informacji osobowych, nie korzystają z cudzych materiałów i są elementem oryginalnego interfejsu szkoleniowego.
